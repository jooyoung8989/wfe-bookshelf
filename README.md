# 월팸 책장 (WFE Bookshelf)

디즈니 월드 오브 잉글리시(World Family) 그림책 **1~12권**을 브라우저에서 바로 읽는 웹 책장입니다.

- **책장 바로 열기**: https://jooyoung8989.github.io/wfe-bookshelf/
- 본문 파일: `wfe-book1.html` ~ `wfe-book12.html` (책장에서 표지를 누르면 같은 경로의 책이 열립니다)
- 배포: GitHub Pages — `gh-pages` 브랜치의 내용이 배포됩니다 (`main`과 내용 동일)

## 폴더 없이 혼자 쓰기
`index.html`(또는 `wfe-bookshelf.html`)과 `wfe-book1.html`~`wfe-book12.html`을 **같은 폴더**에 두고
책장 파일을 열어도 그대로 동작합니다. 책이 다른 폴더에 있으면 책장의 `📁 책 폴더 선택`으로 연결하세요.

## 기록
책마다 붙이는 별(⭐)과 퀴즈 진행도는 그 브라우저의 `localStorage`에 저장돼 기기·브라우저마다 따로 남습니다.
